How this works (click to expand)

Architecture:

Your App → Gatekeep Gateway → LLM Provider (Claude, Ollama, etc)
           (Auth + Routing)

Benefits over direct API calls:

  • Single Authentication: One API key instead of managing multiple provider keys
  • Provider Flexibility: Switch between Claude, Ollama, or other providers without changing your code
  • Self-Hosted: Run locally for privacy and cost control
  • Prompt Gating: Future feature to evaluate/filter prompts before they reach models

How to switch your app to use Gatekeep:

If you're already using the OpenAI client library, just change the API base URL: 

from openai import AsyncOpenAI

# Before (direct to OpenAI):
# client = AsyncOpenAI(api_key=os.getenv("OPENAI_API_KEY"))

# After (using Gatekeep):
client = AsyncOpenAI(
    api_key=os.getenv("GATEKEEP_API_KEY"),
    base_url="http://localhost:8100/v1"
)

# Rest of your code stays the same!
response = await client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[{"role": "user", "content": "Hello!"}]
)

In Python requests (without SDK):

import httpx

async with httpx.AsyncClient() as client:
    response = await client.post(
        "http://localhost:8100/v1/chat/completions",  # Gatekeep URL
        json={
            "model": "claude-sonnet-5",
            "messages": [{"role": "user", "content": "Hello!"}]
        },
        headers={"Authorization": "Bearer sk-your-key"}
    )
